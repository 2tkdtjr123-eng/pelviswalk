# PelvisWalk — 스마트폰 골반 착용형 10m 보행검사

스마트폰을 천골(엉덩이 바로 위)에 스트랩으로 고정하고 10m를 걸으면, 골반 IMU 신호로
보행 속도·분속수·좌우 GCT 밸런스·보폭·골반 3축 움직임·추정 지면반발력·대칭성을 계산해
한 장의 결과지로 보여주는 웹앱입니다. 설치 없이 브라우저에서 동작하며, 모든 계산은 단말에서 처리합니다.

> 본 결과는 참고용이며 의학적 진단을 대체하지 않습니다.

## 구성

| 파일 | 역할 |
| --- | --- |
| `index.html` | 배포용 단일 파일 (앱 + 엔진 포함). 이 파일 하나만 올리면 동작 |
| `app.html` | 앱 화면 원본 (측정 플로우, 결과지) |
| `gait-core.js` | 보행 분석 엔진 (MIT, 오픈소스로 분리 공개용). 브라우저·Node 모두 동작 |
| `build.py` | `app.html` + `gait-core.js` → `index.html` |
| `test/run.js` | 합성 보행 데이터로 엔진 검증 (`node test/run.js`) |

## 폰에서 실제 측정하기 (HTTPS 필수)

모션 센서는 HTTPS 주소에서만 열립니다. 가장 빠른 방법:

1. **GitHub Pages**: 저장소에 `index.html` 업로드 → Settings → Pages → Branch `main` / root → 1~2분 뒤 `https://<아이디>.github.io/<저장소>/` 접속
2. **Netlify Drop**: app.netlify.com/drop 에 `index.html`이 든 폴더를 끌어다 놓기 → 바로 HTTPS 주소 발급

iPhone은 "시작" 버튼을 누를 때 "동작 및 방향" 권한 팝업이 뜹니다. 반드시 **허용**.

## 측정 방법

1. 대상자 정보 입력 → 측정 시작 → 착용 가이드 확인 → **시작**
2. 착용 준비 시간(기본 8초) 동안 폰을 세로, 화면이 바깥(뒤)을 향하게 천골에 고정
3. "움직이지 마세요" → 3초 정지 보정
4. "3, 2, 1, 출발" → **오른발부터** 평소 속도로 10m 걷기
5. 끝에서 멈춰 서면 1.5초 뒤 자동 종료 → 결과지

## 데모·검증 기능

- **데모 · 정상 보행 / 좌우 불균형**: 합성 데이터로 결과지 시연 (PC에서도 동작)
- **원시 데이터 CSV**: 측정 원본 저장 → 검증 데이터셋으로 사용
- **CSV 불러오기**: 저장한 측정을 다시 분석 (발표 때 라이브 실패 대비)
- **분석 신호 보기**: 수직 가속도와 검출된 걸음(IC)을 그래프로 확인 → 영상 걸음 수와 비교
- **좌우 반전**: 좌우 라벨이 반대로 나오면 전환

## 알고리즘 요약

1. 100 Hz 리샘플링 → 20 Hz Butterworth 저역통과(양방향)
2. 정지 보정 구간의 중력 벡터로 수직축 정의, 자이로를 수직·전후·좌우축으로 투영
3. 보행 구간 검출(이동 표준편차) → 자기상관으로 걸음 주기 추정
4. 평활 수직가속도 피크 → 직전 상승 시작점을 초기접지(IC)로 검출 (McCamley 방식 단순화)
5. 첫 걸음 = 오른발(출발 안내), 이후 교대로 좌우 라벨
6. 접촉시간 = IC → 반대발 IC 직후 하중 피크(이지 근사), 보폭 = 역진자 모델 + 총합 10m 보정
7. 골반 ROM = 활보별 각속도 적분(추세 제거), 추정 GRF = 수직 비력 ÷ 정지 중력 (BW)
8. 대칭 지수 SI, 규칙성 Ad1/Ad2(Moe-Nilssen), 활보 시간 CV, 종합 점수(속도 30, 대칭 25, 골반 20, 리듬 15, 충격 10)

참고 범위는 문헌 기반 초안이며, 팀 자체 측정 데이터로 보정할 예정입니다.

## AI 해석 연결

`app.html`의 `AI_ENDPOINT`에 서버 주소를 넣으면 결과 계산 후 지표(이름 제외)를 POST하고,
`{ summary: [3줄], exercises: [{ name, dose, why }] }` 응답으로 종합 소견을 교체합니다.
비워 두면 규칙 기반 해석·운동 권장으로 동작합니다.
